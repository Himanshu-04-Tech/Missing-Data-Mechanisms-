## 4. Discussion

- **[D1] POSSIBLE INTERPRETATION.** Case B conditions (see the Case B finding) may arise because a Random Forest predicts from many columns at once, and unaffected columns such as lat, long and sqft_living15 carry much of the price signal, whereas each OLS coefficient depends on how the one affected column was filled. This was not tested here; it could be examined by checking how prediction changes when only one affected column is imputed at a time. _(source: cases_by_condition.csv)_
- **[D2] POSSIBLE INTERPRETATION.** If predictive differences between imputers are small relative to repeat noise, one possible reason is a ceiling effect: the always-observed columns (lat, long) and correlated columns (sqft_living15 with sqft_living) may let the forest recover most of the signal whatever is imputed. This was not tested; dropping those columns in a side experiment would test it. _(source: predictive_results.csv)_
- **[D3] POSSIBLE INTERPRETATION.** Significance flips were expected to be rare because n stays near 21,000, but for complete-case analysis they occur. A possible reason is that deleting rows lowers n and widens the intervals, so borderline coefficients change status; the number of rows kept is reported in the statistical findings. This was not tested. _(source: stat_recovery_runs.csv)_
- **[D4] POSSIBLE INTERPRETATION.** Complete-case error is larger under MAR than MCAR at most levels. Member 1 suggested this may partly reflect an imperfect linear model (the dropped rows depend on long, which the linear model captures only partly). That guess is untested and is not a finding of this study. _(source: stat_recovery_runs.csv)_

## 5. Limitations

- One dataset (King County house sales, 21,436 rows). Nothing here is claimed for other datasets.
- Missingness is synthetic. MAR depends on long and MNAR on the value itself, with a strength of 1.0 that is our own documented choice; other strengths or drivers may behave differently.
- Location is only partly captured by the predictors (lat and long enter as plain numbers), so the OLS reference is itself an imperfect model.
- Conclusions are about the conditions tested: 3 mechanisms, 5 levels (10% to 50%), 4 imputers, 5 repeats each. No method is claimed to be best in general, and nothing here says MNAR is handled.
- Missingness is injected into the test rows as well, so test error includes imputed test inputs. The diagnostic on complete test rows separates the two sources.
- |z difference| is measured in reference-standard-error units and mixes bias and noise; the signed average is the bias, and averaging signs over coefficients can hide opposite shifts.
- Five repeats give a rough estimate of variability only; small differences between methods should not be over-read.
- The Random Forest is fixed and untuned for every condition; tuning per condition could change the predictive results.
